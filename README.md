<h1>Group Policy Tickets</h1>

<h2>Description</h2>
Project consists of using a virtual homelab environment to perform Group Policy related tasks between a Domain Controller and User computers. 
<br />



<h2>Environments Used </h2>

- <b>Windows 10</b> (21H2)
